## 三类错误如何区分

| 类型                  | 本项目实际证据                                                                                                          | 含义与处理                                                                           |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 审批传输/解码故障     | `Automatic approval review failed`、`stream disconnected before completion`、`error decoding response body`，明确未执行 | 审批未完成，尚没有安全结论；保存原错误，停止该动作，恢复连接后再走正常审批           |
| 操作系统/沙箱访问拒绝 | 普通 Docker CLI 返回 Linux pipe `permission denied`；先前文件操作出现 Access is denied                                  | 操作已经尝试但资源不可访问；区分管道、文件属性、路径权限，不能仅靠增加网络权限解决   |
| 明确安全拒绝          | 本轮没有取得此类拒绝理由                                                                                                | 若以后出现明确策略理由，应按理由缩小动作或提供低风险替代；不能伪装或间接执行同一动作 |

官方说明：自动审阅由独立 reviewer 评估越过沙箱边界的请求，本身不授予文件或网络权限。普通允许范围内操作无需越界审阅；明确拒绝和超时的含义也不同。本次错误是工具明确报告的传输/解码失败，官方页面没有给出这一具体错误的唯一成因。[OpenAI 自动审阅说明](https://learn.chatgpt.com/docs/sandboxing/auto-review)
