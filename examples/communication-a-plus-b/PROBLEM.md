# 通信 A + B

你需要提交两份 C++20 程序：发送端 `sender.cpp` 和接收端 `receiver.cpp`。发送端读取两个整数 a、b，把原始两个整数传给接收端；接收端计算 a+b，并输出答案。两份程序均需正常退出。

## 输入

只有发送端能直接读取题目输入：一行两个整数 a、b，满足 −10¹² ≤ a, b ≤ 10¹²。

接收端的输入是发送端发来的消息。接收端不能直接读取题目输入，也不能向发送端回传消息。

## 输出与通信约定

发送端将 a、b 写到标准输出，使用一个空格分隔，末尾加一个换行，例如 `1 2\n`。接收端从标准输入读取这两个数，把它们的和写到标准输出，例如 `3\n`。

每例发送端的消息最多 **32 字节**，数字、负号、空格、换行均计入。不要将提示语或调试信息写到发送端的标准输出。调试信息可写到标准错误，但也应保持简短。

## 限制

| 项目     | 限制                     |
| -------- | ------------------------ |
| 语言     | C++20                    |
| 时间     | 每例两份程序共享 5000 ms |
| 内存     | 每份程序 64 MiB          |
| 通信方向 | 发送端 → 接收端          |
| 消息长度 | 每例最多 32 字节         |

使用 `long long` 保存输入和答案。输入的绝对值可达 10¹²，答案的绝对值可达 2×10¹²。

## 样例

发送端收到：

```text
1 2
```

发送端传递：

```text
1 2
```

接收端输出：

```text
3
```

## 开始编写

复制 [发送端模板](sender.cpp) 和 [接收端模板](receiver.cpp)，分别放入页面对应的编辑器，再点击“运行测试”。

发送端完成输出后退出即可；接收端读取两个整数后输出结果并退出。不要让任何一端一直等待更多消息。
